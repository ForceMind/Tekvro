TEKVRO / SOFTWARE EVIDENCE WORKBENCH

用证据，看懂软件。

把二进制分析、JavaScript 调查和运行行为观察交给熟悉的 AI 编程助手。Tekvro 负责连接本地分析工具，让推断有来源、结果可复核。

开始使用 ↗ 查看源码
CLI + MCP证据优先本地工具集成中文优先

目前为私有研发版，尚未发布独立的 Tekvro npm 包。安装必须从本仓库源码进行。

WHAT IT DOES

真实分析能力，不是只会猜测

已有的分析适配器按环境提供不同能力。目标软件的保护方式和操作系统会影响分析深度。

01 / 代码制品

JavaScript 与 Electron

检查打包脚本、应用结构、模块依赖、部分静态语义与运行观察证据。

02 / 原生程序

二进制调查

按需连接 Ghidra、Hopper、IDA 等工具，查看函数、符号、引用及反编译结果。

03 / 运行行为

浏览器与网络记录

在授权范围内检查页面脚本、网络捕获和部分事件、执行与来源关系。

04 / 其他分析

Android、.NET 与固件

针对具体制品选择对应适配器；支持情况取决于已安装的分析依赖。

05 / 证据模型

观察、推断与未知

区分实际发现与推断，保留尚不能确定的问题，减少 AI 编造结论。

06 / AI 工作流

从工具到 Agent

通过 MCP 和 CLI 为 Codex、Claude Code 等客户端提供可调用的分析能力。

HOW IT WORKS

四步形成可验证的技术判断

  1. 选择目标提供有权检查的本地应用、文件目录或现有运行数据。
  2. 选择工具Tekvro 发现可用的分析提供方，并向 Agent 暴露受约束的工具。
  3. 收集证据分析文件、结构、函数与运行行为，记录来源和局限。
  4. 形成结论让 AI 解释发现、列出不确定性，再决定是否开展独立实现。

GET STARTED

从你自己的源码开始

需要 Node.js 满足项目声明的版本要求，且有权访问 ForceMind/Tekvro 私有仓库。

Terminal · 初始化
git clone https://github.com/ForceMind/Tekvro.git
cd Tekvro
git submodule update --init --recursive
npm ci
npm run build:cached
node scripts/rea.mjs doctor --json

项目沿用原工程部分内部兼容命令。请勿把公开 npm 上的 rea-agents 当作私有 Tekvro 安装；也不要将待分析的私人内容未经审核发送给外部 AI 服务。

OUR BOUNDARIES

能调查，不等于能还原一切

逆向分析不保证恢复原始源代码，也不能凭客户端制品获得服务端的实现。Tekvro 不自动取得访问权限；专业分析工具的安装、许可证和数据使用约束仍然适用。

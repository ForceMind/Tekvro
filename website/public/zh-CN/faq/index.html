使用与支持

常见问题

完整安装、配置和技术指南统一维护在文档中。

Tekvro 是 AI 模型吗？

Tekvro 是本地 CLI 和 MCP 服务，提供软件检查与证据分析能力。你可以在终端直接调用，也可以连接支持 MCP 的 Agent。

应该从哪里安装？

从 GitHub Release 获取 1.0.0，并按快速开始完成校验与配置。

能恢复任意软件的完整源码吗？

恢复范围取决于目标格式、符号、优化、混淆以及实际可观察的数据。分析结果必须保留局限，不能将推断等同于原始源码。

会自动把目标文件上传吗？

Tekvro 在本地运行分析。连接到远端模型的 Agent 可能把输出带入其上下文；请单独核对客户端的数据处理与隐私设置。

所有分析功能都能直接使用吗？

基础应用分析与可选原生分析有不同依赖。请运行 tekvro doctor，并查阅对应技术指南。环境检测通过只说明其检测范围。

如何更新或报告问题？

审阅新版本的发行说明，安装对应版本并重新检查配置。使用问题与缺陷报告见 SUPPORT.md；安全问题请遵循 SECURITY.md。

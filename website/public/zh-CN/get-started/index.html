从源码到第一次分析

Tekvro 暂时是私有研发项目，还没有独立的公开 npm 版本。下面所有命令均在你有权限访问的本地 Git 副本中执行。

环境构建检查MCP分析注意事项

1. 确认环境

使用与 package.json 兼容的 Node.js：^22.19.0 || ^24.11.0 || >=26.0.0。准备 npm、Git；Ghidra、Hopper、IDA 等只在需要对应原生分析能力时额外安装。

Terminal · 环境 
node -v
npm -v
git --version

2. 克隆与构建源码

先取回仓库和 Git 子模块，按照锁定的依赖安装。构建产物保留在你自己的工作副本中。

Terminal · 安装 
git clone https://github.com/ForceMind/Tekvro.git
cd Tekvro
git submodule update --init --recursive
npm ci
npm run build:cached

不要用 npx rea-agents@latest 代替上述步骤。它会访问原项目的公开 npm 包，并非这里的 Tekvro 源码。

3. 检查功能是否准备好

先运行只读检查，确认能用的分析引擎和所需组件。

Terminal · Doctor 
node scripts/rea.mjs --help
node scripts/rea.mjs doctor --json
node scripts/rea.mjs capabilities --json

4. 连接 Codex 等 AI 客户端

推荐先查看配置计划；只有确认目标客户端、路径、备份以及准备写入的启动命令正确之后，再执行实际配置。

Terminal · MCP 
node scripts/rea.mjs doctor --client codex --json
node scripts/rea.mjs setup --client codex --dry-run --json
TEKVRO_LANG=zh-CN node scripts/rea.mjs setup --client codex

私有 Tekvro 从源码注册时使用本机 Node.js 加本仓库的 CLI 绝对路径，不会自动下载公开的 rea-agents。Windows PowerShell 可先执行 $env:TEKVRO_LANG="zh-CN"，再运行最后一条 node 命令。

5. 第一次本地调查

下面的示例针对你拥有检查权限的 JavaScript 或 Electron 解包目录。请按实际情况替换绝对路径。

Terminal · 分析 
node scripts/rea.mjs analyze-javascript-application /absolute/path/to/app --json

请向 AI 明确要求区分“观察到的事实”“合理推断”和“仍然未知”。重要结论应能回溯到相应的文件、调用链或运行记录。

6. 安全、更新与局限

  • 只分析你有权检查的目标；不要在未经审核时上传商业秘密、密钥或含个人数据的证据。
  • 私有开发版已禁用原 npm 自动升级。更新本仓库请审阅 Git 变更后自行运行 git pull --ff-only，再执行 npm ci 和 npm run build:cached。
  • 某些平台需要第三方原生分析软件；检测通过不代表你拥有这些软件的许可证。
  • REA 内部 CLI/MCP 标识处于兼容过渡阶段，不代表 Tekvro 已有独立公开发行包。

Tekvro 1.0.0

开始使用

安装本地 CLI，检查环境，然后将 Tekvro 连接到支持 MCP 的客户端。

1. 安装发行包

准备 Node.js 24 或更新版本，以及 npm。安装器从 GitHub Release 下载版本固定的包，验证 SHA-256 后安装；它不会替你安装系统依赖。

Terminal 
curl -fsSL https://raw.githubusercontent.com/ForceMind/Tekvro/v1.0.0/install.sh -o install-tekvro.sh
bash install-tekvro.sh --version 1.0.0

也可以从 1.0.0 发行页下载 tekvro-1.0.0.tgz 与 SHA256SUMS，完成校验后运行 npm install -g ./tekvro-1.0.0.tgz。

此版本通过 GitHub Release 发布。源码安装与其他系统的步骤见安装与发行指南。

2. 检查环境与配置计划

Terminal 
tekvro --version
tekvro doctor --json
tekvro setup --dry-run --json

审阅计划中的客户端、路径、启动命令和备份，再执行 tekvro setup 写入客户端配置。安装器本身不会修改 MCP 客户端配置。

客户端配置参考 →

3. 检查一个本地应用

Terminal 
tekvro analyze-javascript-application /absolute/path/to/app --json

使用你有权分析的目录，要求 Agent 标明观察、推断与未知项。分析结果的来源和局限应随结论一并保留。

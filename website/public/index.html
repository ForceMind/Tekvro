One analysis interface for terminal and agent

Start with a local application directory you are authorized to inspect. Review its structure and evidence, then ask a more specific question.

Terminal 
tekvro analyze-javascript-application /absolute/path/to/app --json

Replace the example path with your application directory. Runtime observation and native analysis may need additional configuration; consult the relevant technical guide for coverage.

Tekvro 1.0.0

Get started

Install the local CLI, check your environment, then connect Tekvro to an MCP client.

1. Install the release

Use Node.js 24 or newer and npm. The installer downloads the pinned package from GitHub Release and verifies its SHA-256 checksum before installation. System dependencies must already be available.

Terminal 
curl -fsSL https://raw.githubusercontent.com/ForceMind/Tekvro/v1.0.0/install.sh -o install-tekvro.sh
bash install-tekvro.sh --version 1.0.0

You can also download tekvro-1.0.0.tgz and SHA256SUMS from the 1.0.0 release page, verify the checksum, then run npm install -g ./tekvro-1.0.0.tgz.

This version is distributed through GitHub Release. See the installation guide for source builds and other environments.

2. Check the environment and setup plan

Terminal 
tekvro --version
tekvro doctor --json
tekvro setup --dry-run --json

Review the selected client, paths, launch command and backup plan. Run tekvro setup when you are ready to write the client configuration. Installation alone does not change MCP client settings.

3. Inspect a local application

Terminal 
tekvro analyze-javascript-application /absolute/path/to/app --json

Choose a directory you are authorized to inspect. Ask your agent to distinguish observations, inferences and unknowns, and to retain sources and limitations with each conclusion.

Usage and support

Frequently asked questions

The documentation is the complete reference for installation, configuration and technical workflows.

Is Tekvro an AI model?

Tekvro is a local CLI and MCP server for software inspection and evidence analysis. Use it directly in a terminal or connect it to an MCP agent.

Where do I install it?

Get version 1.0.0 from GitHub Release, then follow Get started to verify and configure it.

Can it recover the complete source of any application?

Recoverability depends on the target format, symbols, optimization, obfuscation and observable data. Keep those limitations with the result; an inference is not original source code.

Does it upload target files automatically?

Tekvro runs analysis locally. An agent connected to a remote model may include tool output in model context. Check that client’s data handling and privacy settings separately.

Is every capability available immediately?

Application inspection and optional native analysis have different dependencies. Run tekvro doctor and read the relevant technical guide. A successful environment check establishes only what it checks.

How do I update or report a problem?

Review the release notes, install the selected version and check your configuration again. See SUPPORT.md for questions and defects. Follow SECURITY.md for sensitive security reports.

# Tekvro 产品路线

Tekvro 以可追溯的证据连接本地软件分析、命令行和 MCP 工作流。版本发布优先保证安装可复现、契约稳定和能力范围清晰。

## 1.0.0 交付范围

- 版本固定的 CLI 安装包、完整源码包、校验文件与发行说明。
- CLI 与 MCP 的共享分析工作流，以及带来源、覆盖和局限的 Evidence 结果。
- JavaScript 应用、离线制品、浏览器与应用观察、证据查询和比较等能力；具体功能依赖所选格式、宿主环境和可用引擎。
- 中英文项目入口、安装与使用指南、贡献流程、支持渠道和安全报告说明。
- 分层测试、完整测试清单核对、平台打包与对应真实工具链验收。每个版本的实际执行结果以发行记录和 CI 为准。

发行资产与版本说明见 [Releases](https://github.com/ForceMind/Tekvro/releases)，当前安装方法见[安装指南](installation.md)。

## 已有验收范围

实际工作流记录包括 Linux x64 的 H5/JavaScript、WASM 与部分本地分析引擎，以及 macOS arm64 的 Electron 生命周期、IPC 和清理。平台包检查还覆盖部分 Linux、macOS 和 Windows 组合；包能安装不表示这些平台上的所有可选引擎均已运行。

上述记录分别限定于所用样本、宿主与提交。1.0.0 的最终资格以该版本发行记录和对应 CI 为准，不将历史成功自动算作当前版本已通过。后续每项支持声明都应能追溯到具体工作流记录。

## 支持范围的推进条件

新增平台或引擎支持须提供对应宿主、工具和真实工作流的记录。当前部分主动应用观察仍有宿主进程归属和清理限制；未配备的商业引擎实例、实体设备与动态目标也不计为已验收。

固件相关参数的后续验证需保留成对范围与独占输出发布规则，并准备真实引擎环境。合成样本和协议夹具用于验证各自边界，真实引擎资格单独记录。

每组变更通过独立审查和当前提交的检查后进入主线。稳定版本与主线开发分别记录，未验证的范围继续显示为未知或不可用。

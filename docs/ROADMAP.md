# Tekvro 探核 · 独立产品路线图

本路线以 **从零独立研发** 为前提。功能规划不表示已经完成。

## v0.1（当前源码实现）

- [x] Node.js 22+、零运行时依赖、中文优先 CLI
- [x] 根目录白名单与路径越界防护
- [x] 目录文件清单、类型初判、大小汇总
- [x] 文件头识别、SHA-256 和只读 ASCII 字符串检查
- [x] 本地 MCP stdio 工具
- [x] 自动化测试与私有仓库 CI

## v0.2（可信分析）

- [ ] 各二进制格式的结构化解析器（ELF/PE/Mach-O/WASM），含架构、段、节、符号
- [ ] 提取 HTML/JS 的本地依赖图，并建立可复核的引用关系
- [ ] Evidence 数据模型：可观察事实、推断、未知项，附来源位置和置信说明
- [ ] 统一的分析报告导出（JSON/Markdown）
- [ ] 针对符号链接竞态、文件尺寸和资源使用增加深度安全测试

## v0.3（AI 协作）

- [ ] 使用维护良好的正式 MCP SDK 对不同客户端与协议版本进行兼容性验证
- [ ] 任务队列、取消、进度通知、会话及证据文件管理
- [ ] 可调的内容脱敏、敏感文件拦截和模型数据上送预审
- [ ] 首批 H5/JavaScript 游戏结构调查工作流

## v0.4（独立分析工作台）

- [ ] 中文/英文 Web UI 与本地运行服务
- [ ] 文件拖入、证据树、结构图、差异报告、可复核分析笔记
- [ ] WASM、APK、Electron 深入分析适配器（独立实现或经许可集成）
- [ ] Mac / Windows / Linux 正式打包和签名
- [ ] 独立品牌、官网、版本更新和供应链安全管理

## 交付准则

每个版本必须说明实际完成项、测试环境、未覆盖能力和已知风险。不得把“猜测的软件行为”描述成已实证的事实，也不能把其他项目的源代码通过删除署名转为自有作品。

# Tekvro 1.0.0

[中文](#中文) · [English](#english) · [GitHub Release](https://github.com/ForceMind/Tekvro/releases/tag/v1.0.0)

## 中文

Tekvro 1.0.0 是首个独立公开版本。它通过命令行和 MCP 提供本地软件分析、运行观察与可复核的结构化证据。

### 本次发布

- 应用结构分析：检查 JavaScript 构建目录和桌面应用包，追踪模块、依赖、代码关系及源码映射。
- 运行观察：通过选定的本地调试接口观察脚本、网络和支持的运行时行为。
- 程序与文件检查：为支持的原生程序、移动应用、托管程序、数据库及离线制品提供对应分析入口。
- 证据与比较：保留输入身份、来源位置、观察事实、覆盖范围和未知项，支持后续查询与制品比较。
- 安装与配置：发布可安装的编译运行包，提供中文帮助、环境诊断及独立的配置预览和应用步骤。

这些条目描述 1.0.0 的产品范围；具体操作及其条件见[使用文档](https://github.com/ForceMind/Tekvro/blob/v1.0.0/docs/index.md)。

### 下载和安装

| 文件                         | 用途                                                          |
| ---------------------------- | ------------------------------------------------------------- |
| `tekvro-1.0.0.tgz`           | 含编译运行时的 CLI/MCP 安装包                                 |
| `tekvro-1.0.0-source.tar.gz` | 完整源码，包含固定的 Git 子模块内容                           |
| `SHA256SUMS`                 | 两个归档及发行清单的 SHA-256                                  |
| `release-manifest.json`      | 产品版本、源码提交与树、归档大小和摘要、构建 Node.js/npm 版本 |

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/ForceMind/Tekvro/v1.0.0/install.sh -o install-tekvro.sh
bash install-tekvro.sh --version 1.0.0
tekvro --version
tekvro doctor --json
```

也可下载 `.tgz`，按[分发说明](https://github.com/ForceMind/Tekvro/blob/v1.0.0/docs/zh-CN/distribution.md)校验后运行 `npm install --global ./tekvro-1.0.0.tgz`。Windows 使用下载归档的安装方式。

本次仅通过 GitHub Release 分发。包元数据保留 `private: true` 防止误上传注册中心，这不妨碍安装本地归档。安装包仍需 npm 获取其运行依赖，并非完全离线的依赖合集。

安装后先用 `tekvro setup --dry-run` 查看配置计划，再运行 `tekvro setup` 应用选定的客户端设置。

### 运行要求与验证边界

Node.js 运行范围为 `^22.23.4 || ^24.22.1 || >=26.12.1`；主要 CI 使用 Node.js `24.22.1`；开发声明的 npm 版本为 `11.16.0`，发行清单记录实际构建版本。Windows 路径边界另有 Node.js `22.23.4` 检查。这不是每个受支持 Node.js 主版本的完整测试矩阵。

CI 对可移植测试清单、源码和编译后边界进行检查，并按变更选择宿主包验收、文档和真实工具验证。GitHub 发布流程还会安装实际 `.tgz` 并执行运行包 canary，然后校验四个发行资产。确切的提交、构建运行和结果以对应发行页及 Actions 记录为准；历史测试次数不作为本版本的通过证明。

CLI/MCP 提供 Windows、macOS 和 Linux 入口。具体功能取决于宿主、目标格式、权限及可选工具。没有配置或没有实际验证的能力不因发布而获得支持保证。分析成功也可能包含部分结果、未知项和局限；客户端制品不能证明未观察的服务端实现。

问题反馈见[支持说明](https://github.com/ForceMind/Tekvro/blob/v1.0.0/SUPPORT.md)，安全报告见[安全说明](https://github.com/ForceMind/Tekvro/blob/v1.0.0/SECURITY.md)，许可见 [LICENSE](https://github.com/ForceMind/Tekvro/blob/v1.0.0/LICENSE) 和 [THIRD_PARTY_NOTICES.md](https://github.com/ForceMind/Tekvro/blob/v1.0.0/THIRD_PARTY_NOTICES.md)。

## English

Tekvro 1.0.0 is the first standalone public release. Its CLI and MCP server provide local software analysis, runtime observation and structured evidence that can be inspected and reused.

### Release scope

- Inspect JavaScript application builds and desktop packages, including modules, dependencies, code relationships and source maps.
- Observe selected local debugging interfaces, scripts, network activity and supported runtime behavior.
- Analyze supported native programs, mobile applications, managed programs, databases and offline artifacts.
- Preserve input identity, source locations, observations, coverage and unknowns for evidence queries and artifact comparisons.
- Install a compiled runtime package, inspect the machine with doctor, and review client configuration separately from installation.

See the [documentation](https://github.com/ForceMind/Tekvro/blob/v1.0.0/docs/index.md) for each operation's conditions and limits.

### Assets and installation

The release contains exactly four assets: `tekvro-1.0.0.tgz`, `tekvro-1.0.0-source.tar.gz`, `SHA256SUMS` and `release-manifest.json`. The runtime package includes compiled code; the source archive includes pinned submodule contents. The manifest records the source commit and tree, archive hashes and sizes, and build runtime versions. `SHA256SUMS` covers both archives and the manifest.

On macOS or Linux, use the versioned installer shown above. Alternatively, download and verify the runtime archive, then run:

```bash
npm install --global ./tekvro-1.0.0.tgz
tekvro --version
tekvro doctor --json
tekvro setup --dry-run
```

Windows uses the downloaded archive installation. Review the setup plan before running `tekvro setup`. The [distribution guide](https://github.com/ForceMind/Tekvro/blob/v1.0.0/docs/zh-CN/distribution.md) includes checksum commands and update instructions.

This is a GitHub Release distribution. No npm registry package or MCP Registry entry is published. `private: true` prevents registry publication while allowing local archive installation. npm still obtains runtime dependencies; the archive is not a complete offline dependency bundle.

### Runtime and verification limits

The supported Node.js range is `^22.23.4 || ^24.22.1 || >=26.12.1`. The main CI suites use Node.js `24.22.1`. Development declares npm `11.16.0`; the manifest records the actual build versions. Selected Windows path checks also run on Node.js `22.23.4`. This does not establish full-suite coverage on every supported Node.js major version.

CI checks the portable test inventory and source/compiled boundaries, selecting native package, documentation and real-tool lanes according to changes. Publication also installs and exercises the actual `.tgz` before verifying the four release assets. The release and Actions records identify the exact revision and results; historical test totals are not proof that this version passed.

CLI/MCP entrypoints are available for Windows, macOS and Linux. Individual operations depend on the host, target format, permissions and configured tools. Unavailable or unverified optional capabilities carry no general platform guarantee. Successful analysis can still contain partial results, unknowns and limitations; client artifacts do not prove an unobserved server implementation.

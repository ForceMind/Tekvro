# 常见问题

**Tekvro 是新写的逆向引擎吗？**  
不是。它基于 MIT 授权的 REA 6.1.0 源码改造，主要连接 Agent、专业分析引擎和 Evidence 记录。

**是否可以还原任意软件的原始源代码？**  
不保证。源代码、符号、运行上下文缺失或被保护时，结果会有显著不确定性；服务器端逻辑不会凭空出现。

**为什么终端里还存在 `rea` 和 `rea-agents`？**  
这是兼容旧客户端配置的命令与注册键。源码 npm 包名已迁移为 `tekvro`、MCP Registry 草案名称已迁移为 `io.github.forcemind/tekvro`，但**均未独立正式发布**，旧 CLI 别名暂时保留。

**我在中国大陆可以使用吗？**  
代码在本地运行，但 GitHub/npm 和外部引擎下载可能受网络条件影响，联网 AI 模型也需要另行配置。我们不保证任何第三方服务的可用性。

**为什么会看到英文？**  
目前支持基于 `TEKVRO_LANG=zh-CN` 的部分 CLI 人类帮助及交互式设置提示，也提供 [JavaScript/H5/Electron 中文分析指南](javascript-h5-electron.md)；大量底层错误、专业工具说明和旧技术手册仍为英文，后续分批翻译并保持术语对应。

# Tekvro · 技术架构（原创 v0.1）

```text
用户 / AI 编程助手
      │
      ├─ CLI（中文优先）
      │      │
      └─ MCP stdio（JSON-RPC）
             │
       授权根目录 Scope
             │
       只读证据检查层
      ┌──────┼─────────────┐
      │      │             │
  目录清单  文件签名      字符串提取
      │      │             │
      └──────┴──────┬──────┘
                    │
           SHA-256 / JSON 结果
```

## 技术选择

- **JavaScript ESM / Node.js 22+**：内置的文件系统、哈希、流式读取和测试工具。
- **没有运行时 npm 依赖**：避免初期供应链复杂性和从旧项目复制依赖清单。
- **源文件不执行**：任何分析只读取用户显式指定的受权文件。
- **MCP stdio**：通过终端流传输 JSON-RPC，输出仅用来发送响应，不混入终端调试日志。
- **同一 Scope 边界**：无论 CLI 或 MCP，绝对路径、相对越界和指向外部的 symlink 都会受到检查。
- **可机器处理结果**：约定 JSON 的字段名稳定，中文是人类界面文本，不影响结构化数据。

## 安全限制

最大文件哈希尺寸 64 MiB；字符串提取检查前 1 MiB；扫描最多 500 个普通文件、最大深度 8。默认不遍历 `.git`、`node_modules`、`.cache`、`coverage`，也不跟随目录内的符号链接。

当前属于独立基础版本，不承诺完整 MCP 所有可选协议能力、并发任务、持久 Evidence 数据库、执行沙箱或漏洞分析。未来增加功能时需明确兼容性与安全模型。

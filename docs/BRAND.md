# 品牌与命名

## 名称

| 项目         | 用法                                |
| ------------ | ----------------------------------- |
| 英文名称     | Tekvro                              |
| 中文名称     | 探核                                |
| 中英文组合   | Tekvro · 探核                       |
| 中文标语     | 用证据看懂软件。                    |
| 英文标语     | Investigate software with evidence. |
| CLI 入口     | `tekvro`                            |
| MCP 服务标识 | `io.github.forcemind/tekvro`        |

Tekvro 建议发音为 **TEK-vro**，两个音节。英文名称使用首字母大写；命令、包名及代码标识使用对应技术契约中的大小写。

## 产品表述

Tekvro 是本地软件分析工具，通过 CLI 与 MCP 提供静态检查、运行观察和证据查询。介绍具体能力时，应同时说明目标格式、可观察范围、所需工具和验证条件。

产品文案优先描述使用者能够完成的任务以及报告提供的事实。使用“观察”“推断”“未知”和“覆盖范围”表达证据强度，避免保证任意源码恢复、完整行为重现或全部系统支持。

# Tekvro · 安全与授权

1. **合法授权**：只检查自己拥有或获得授权的软件、文件、记录与制品。
2. **默认只读**：不启动、注入、调试被检查的程序，不执行目标脚本，不访问外部网络。
3. **根目录隔离**：CLI 默认限制在当前目录；MCP 必须指定 `TEKVRO_ROOT` 或 `--root`。禁止路径越界，拒绝解析至根目录外的 symlink。
4. **资源上限**：哈希读取最大 64 MiB、字符串前 1 MiB、目录最多 500 文件与 8 层深度。即使如此，未知文件仍应谨慎处理。
5. **敏感信息**：字符串提取可能包含账号、密码、Token 等内容。允许本地检查并不意味着允许转发给联网 AI 模型。将证据发送至远端模型前，应自行检查和脱敏。
6. **不提供执行沙箱**：目标文件绝不应被本工具当成命令执行。也不应以管理员权限运行未充分审查的新代码。
7. **不自动发布**：项目私有且 `UNLICENSED`，没有 npm 或 MCP Registry 的外部发布动作。

若发现安全问题，应私下提交给项目维护者，不要在公共 Issue 中附敏感样本。
